## How to review

- Read the Korean and English side by side. Check meaning first, then natural dialogue, tone, and names.
- Send feedback using a review number, for example: **R042 — change “…” to “…” because …**. Each number links to its exact catalog entry.
- “Source index” is the original zero-based TextList index, not a file line number. Missing indices and separate variants are intentional.
- `/n` marks an in-game line break. Other slash codes such as `/20d` and `/2c`, placeholders, and tags are retained for reference; review the surrounding prose. This Markdown view does not expose all whitespace; the linked catalog is authoritative for exact formatting.
- Start with the flagged questions below, or read the full scene tables. General name/voice review applies to all dialogue, even rows without a specific flag.
- Feedback does not automatically modify the catalogs. Tell me which changes you want applied.
