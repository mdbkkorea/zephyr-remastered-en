# 西风狂诗曲重制版 · 简体中文汉化工具

小时候，我很喜欢《西风狂诗曲》。多年以后，想再走一遍那段旅程，也希望更多中文玩家能读懂它的故事，于是有了这个为爱发电的汉化项目。

这是一个**免费、非官方、由玩家维护**的项目，与游戏开发商、发行商没有隶属或授权关系。请购买并支持正版：**[Steam 官方商店](https://store.steampowered.com/app/5099430/)**。本工具不能代替游戏，也不提供游戏下载、破解或绕过购买验证的功能。

## 下载与使用

1. 在 [Releases](https://github.com/wanjizheng/zephyr-remastered-zh-cn/releases) 下载 `Zephyr-Chinese-Patcher-*.zip`。不要下载页面上的 Source code 来当安装包。
2. 将 ZIP 完整解压到一个可写文件夹；不能只取出 EXE。
3. 保存并正常退出游戏。运行 `ZephyrChinesePatcher.exe`。无需另外安装 Python、.NET 或 Unity。
4. 工具会尝试找到 Steam 游戏目录，也可以手动选择包含 `ZephyrRemastered.exe` 的文件夹。
5. 点击 **安装汉化**，等待完成和校验通过。处理期间不要启动游戏、验证游戏文件或强行关闭工具。
6. 自行启动游戏。本汉化复用韩语资源；若游戏语言设为英文，请切换为 **韩语 / 한국어**。工具不会改写你的语言设置。需要还原时退出游戏，再点击 **恢复原版**。恢复的是安装前的原版文件，韩语／英文由游戏或 Steam 的语言设置选择。

工具采用本地资源重建，第一次安装需要一些时间和临时磁盘空间。建议系统盘与游戏所在磁盘均预留至少 **5 GB**；实际占用依游戏文件和更新次数而异。默认以普通权限运行，只有游戏目录没有写权限时才需要调整权限或使用管理员身份。

Windows 可能对尚未建立信誉、未做 Authenticode 签名的个人软件显示提示。请只从本仓库 Releases 下载，核对发布的 SHA-256；不要关闭杀毒软件。更新元数据的签名与 Windows 程序签名是两回事。

## 检查更新

打开工具后会检查本仓库 GitHub Releases，也可点击 **检查更新**。发现更新时显示提示；点击后打开经过签名元数据验证的发布页面，由你下载新版并完整解压，再运行新版工具更新汉化。

**不会静默安装更新，也不会在游戏运行时替换资源。** 网络不可用时，本地安装和恢复功能仍然可用。工具只访问 GitHub 的公开发布接口，不上传游戏文件、存档或个人信息，不要求 GitHub 登录。

## 备份、恢复与故障

- 原版备份和事务记录存放在 `%LOCALAPPDATA%\ZephyrChinesePatcher\`，按游戏目录区分。不要在需要恢复时删除此目录。
- 安装前检查游戏版本和资源 SHA-256，自动保存原版备份；本地生成结果再次与发行版 SHA-256 核对后才写入。
- 写入采用逐文件替换与事务日志。操作中断后，重新运行并点击 **恢复上次操作**。若文件又被 Steam 或其他工具修改，会停止而非覆盖未知版本。
- 存档不在修改清单中；恢复原版不会回退游戏进度。对重要存档，仍可自行按平时习惯备份。
- 从其他工具或手动复制安装的汉化，不能凭空获得原版备份。请先使用当时的原版备份恢复，或使用 Steam 的“验证游戏文件完整性”，然后由本工具安装。
- Steam 验证完整性或游戏更新可能移除汉化；需要重新安装兼容版本。
- 工具保留事务备份与中间生成结果，便于故障恢复。第一版尚无自动清理功能，请勿在未完成事务时手动清理。
